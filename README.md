# Deepanshu Yadav: portfolio

Next.js (App Router), TypeScript, Tailwind CSS, Motion, Lucide.

## Run locally
    npm install
    npm run dev

## Update content
All text, links and projects live in `lib/data.ts`. Replace `public/resume.pdf` to update the resume.

## Deploy on Vercel
1. Push this folder to a new GitHub repository.
2. In Vercel, choose Add New, then Project, and import the repository.
3. Keep the detected Next.js settings and click Deploy. No environment variables are required.
4. Optional: after you attach a custom domain, set `NEXT_PUBLIC_SITE_URL` (e.g. https://yourdomain.com) so the sitemap and social previews use it.
